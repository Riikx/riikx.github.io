# Trator reutilizado do treinamento

Origem: repositório Riikx/Treinamento-de-piloto, visualizador `js/tractor-viewer.js`, modelo `models/lamborghini_r6_optimized.glb` e antena `models/nav900_optimized.glb`.

O visualizador foi adaptado para os caminhos deste portfólio, sem o console de depuração. Ele gera uma imagem superior do mesmo modelo para o simulador de cana. O código de carregamento local em base64, controles da câmera e foco nos componentes são do projeto de treinamento.

O Three.js continua sendo carregado da versão 0.180.0 no esm.sh, como no projeto original. A visualização 3D precisa de WebGL e conexão para carregar essas dependências. Os modelos ficam nesta pasta e não dependem de acesso ao repositório privado.

O nome do arquivo original identifica o modelo como Lamborghini R6 125 DCR e inclui www.vecarz.com. Esta reutilização preserva os arquivos do projeto; não altera direitos ou atribuição do modelo.
